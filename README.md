# myenv

## Install

```sh
mkdir -p $HOME/workspace/personal-repositories
git clone https://github.com/vgavriilidis/myenv.git $HOME/workspace/personal-repositories/myenv
cd $HOME/workspace/personal-repositories/myenv
./install_dev_setup.sh
```

The script is idempotent — re-running it is safe.

## Manual steps (not automated)

A few things can't be done by the script and need to be run once by hand.

### Kitty: pick a theme

`kitty/kitty.conf` includes `current-theme.conf`, which is generated by kitty's theme picker:

```sh
kitty +kitten themes
```

Pick a theme and save. This writes `~/.config/kitty/current-theme.conf`.

### Kitty: reload config

After changing `kitty.conf`, reload without restarting:

- Shortcut: `ctrl+shift+f5`
- Or: `kitty @ load-config` (requires `allow_remote_control yes`)

### Fonts

`kitty.conf` references `font-3270-nerd-font`. Install it manually:

1. Download from https://www.nerdfonts.com/font-downloads
2. Move `.ttf`/`.otf` files into `~/Library/Fonts`
3. Verify: `kitty +list-fonts | grep -i 3270`

### tmux plugins

After first launch, install plugins via TPM:

- Open tmux, press `prefix + I` (capital i) to fetch plugins.

### Neovim plugins & LSPs

Open `nvim` once. Two things happen on first launch:

1. `lazy.nvim` bootstraps and syncs plugins.
2. `mason.nvim` installs the configured LSP servers and tools (bashls, gopls, lua_ls, pyright, tailwindcss, biome, prettier, shellcheck, stylua, …). This runs in the background and may take a minute.

Check progress / install manually:

```vim
:Lazy
:Mason
```

If a server didn't auto-install, run `:MasonInstall <name>` from the `:Mason` UI. The full list lives in `nvim/lua/vasilis/plugins/lsp/mason.lua`.

### Shell

If `zsh` isn't your default shell yet:

```sh
chsh -s "$(which zsh)"
```

### Git identity

The tracked `.gitconfig` includes `~/.gitconfig.local` for per-machine identity. The install script seeds it with `TODO` placeholders on first run — fill them in:

```sh
$EDITOR ~/.gitconfig.local
```

```ini
[user]
  name = Your Name
  email = you@example.com
```

`~/.gitconfig.local` is intentionally untracked.
